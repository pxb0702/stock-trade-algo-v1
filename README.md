# Stock Trade Algo v2.1 (A股双模自适应量化交易系统 · 自选股动态管理版)

专为 **中国 A 股市场 (China A-Shares)** 设计的高性能自适应量化回测与交易策略系统。基于真实 A 股微观制度建模（严格 **T+1 制度**、**100 股整手限制**、**印花税 0.05%**、**券商佣金万三且最低 5 元**、**过户费** 与 **滑点**）。

在 **v2.1** 中，系统不仅拥有经过平安银行等标的验证的高胜率 **双模自适应体系（Dual-Regime Architecture）**，更全面支持了 **用户自定义增加与删除自选股票/ETF 选项**，数据本地持久化存储，自由扩展回测标的池。

---

## 🌟 v2.1 新增核心功能：自选股票动态管理 (Custom Watchlist)

1. **自由添加任意 A 股 / ETF 标的**：
   - 支持在 Web 顶部导航点击 `+ 添加自选` 或在左侧控制台点击 `设为/加入自选`；
   - **名称自动智能解析**：输入 6 位数字代码（如 `600036`、`000333`、`510500` 等），系统在毫秒级自动联网识别其官方中文证券名称（招商银行、美的集团、中证500ETF 等），亦支持手动修改；
   - **热门资产一键预设**：内置招商银行、美的集团、紫金矿业、中证500、科创50、长江电力等热门股票与行业龙头一键标签。

2. **自选股一键删除与管理**：
   - 顶部快捷胶囊标签（Pills）右侧带有 `×` 快捷删除按钮，点击即刻移出；
   - 侧边栏提供 `移出自选` 快捷按钮；
   - 提供 `恢复默认自选池` 按钮，防止误删后无法找回默认组合。

3. **数据本地持久化与跨平台联动**：
   - 自选股实时持久化保存至 `data/watchlist.json`，重启应用或刷新浏览器后配置完全保留；
   - 前后端 RESTful API 完整对接（`/api/watchlist`、`/api/watchlist/add`、`/api/watchlist/delete`、`/api/watchlist/reset`、`/api/stock/resolve`）。

## 💡 v2.0 双模自适应算法机制回顾

1. **宏观牛熊多空过滤器 (Macro Trend Slope Filter)**：
   - 引入 60 日均线方向判定：
     $$\text{Slope} = \text{SMA}_{60}(t) - \text{SMA}_{60}(t-5)$$
   - 当价格位于 60 日均线下方且均线向下发散时，系统强制保持 **100% 现金空仓避险**，规避单边大跌风险。

2. **双模自适应开仓架构 (Dual-Regime Entry Architecture)**：
   - **Mode A 顺势波段突破 (Trend Momentum)**：在宏观多头环境下，结合 EMA12/EMA26 金叉、MACD 柱加速与 RSI 动量确认入场；
   - **Mode B 恐慌极值超跌反弹 (Oversold Panic Reversal)**：当标的遭遇极端非理性砸盘（$\text{RSI}_6 < 22$ 或击穿布林下轨），出现长下影线或阳线企稳时捕获极高盈亏比的超跌反弹机会。

3. **多级利润锁定与动态止损体系 (Multi-Stage Profit Lock & Risk Hierarchy)**：
   - **目标波段止盈 (Target Take Profit)**：设定波段预期止盈位（默认 `+8.0%`），达到后自动止盈平仓；
   - **严格硬止损 (Hard Stop Loss)**：单笔亏损严格拦截在 `-3.0%`，杜绝深套；
   - **保本保盈提升 (Breakeven Lock & ATR Trailing Stop)**：单笔浮盈超过 `+2.0%` 后，ATR 追踪止损线自动推升至成本价上方；
   - **破位早退 (SMA20 Breakdown Exit)**：若持仓未能迅速发酵并下破 20 日均线，系统在小幅损耗内有序撤退。

## 🚀 快速启动指南

### 1. 命令行 CLI 回测 (以平安银行为例)

```bash
# 运行平安银行 (000001) v2 优化回测
python algo_trading_v1/run_backtest.py --code 000001 --start 2021-01-01 --end 2024-12-31 --tp 0.08 --sl 0.03

# 运行比亚迪 (002594) 回测
python algo_trading_v1/run_backtest.py --code 002594 --start 2021-01-01 --end 2024-12-31 --tp 0.10 --sl 0.035

# 运行贵州茅台 (600519) 回测
python algo_trading_v1/run_backtest.py --code 600519 --start 2021-01-01 --end 2024-12-31 --tp 0.08 --sl 0.03
```

**CLI 参数说明**：
- `--code`: 标的代码（如 `000001` 平安银行, `510300` 沪深300ETF）
- `--start` / `--end`: 回测时间窗口
- `--capital`: 初始本金（默认 100,000 元）
- `--tp`: 目标波段止盈比例（默认 `0.08` 即 `8%`）
- `--sl`: 严格最大硬止损比例（默认 `0.03` 即 `3%`）
- `--atrm`: ATR 追踪止损推升倍数（默认 `2.2`）
- `--pos_pct`: 仓位资金分配比例（默认 `0.95`）
