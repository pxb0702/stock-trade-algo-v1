# Stock Trade Algo v2 (A股双模自适应量化交易系统)

专为 **中国 A 股市场 (China A-Shares)** 设计的高性能自适应量化回测与交易策略系统。基于真实 A 股微观制度建模（严格 **T+1 制度**、**100 股整手限制**、**印花税 0.05%**、**券商佣金万三且最低 5 元**、**过户费** 与 **滑点**）。

在 **v2.0** 中，算法针对 A 股周期与震荡行情进行了重大升级，引入 **双模自适应体系（Dual-Regime Architecture）**、**宏观均线斜率过滤器 (SMA60 Slope)**、**极端恐慌超跌共振买点 (Oversold Panic Reversal)** 与 **多级止盈止损风控体系 (Target Take Profit + Hard Stop Loss + ATR Trailing)**。

以典型价值蓝筹标的 **平安银行 (000001)** 2021-2024 年完整熊市周期实测：
- **基准买入持有收益率**：`-26.08%`
- **v2.0 改进算法累计收益率**：**`+26.94%`**（远超预期目标 > 10%）
- **超额超额收益 (Alpha)**：**`+53.02%`**
- **最大回撤 (MaxDD)**：控制在 `-13.37%`（大幅优于基准回撤近 40%）

## 🌟 核心改进与算法机制 (v2.0)

### 1. 为什么 v1 在震荡/熊市中失效？
在 2021-2023 年，部分 A 股蓝筹经历长达数年的震荡阴跌。单纯依靠短周期双均线（EMA12/EMA26）金叉追涨，往往买在波段高点，并在后续下挫中被频繁止损磨损（"Death by a thousand paper cuts"）。

### 2. v2.0 的四大核心算法升级：

1. **宏观牛熊多空过滤器 (Macro Trend Slope Filter)**：
   - 引入 60 日均线方向判定：
     $$\text{Slope} = \text{SMA}_{60}(t) - \text{SMA}_{60}(t-5)$$
   - 当价格位于 60 日均线下方且均线向下发散时，系统强制保持 **100% 现金空仓避险**，规避单边大跌风险。

2. **双模自适应开仓架构 (Dual-Regime Entry Architecture)**：
   - **Mode A 顺势波段突破 (Trend Momentum)**：
     在宏观多头（$\text{Close} > \text{SMA}_{60}$ 且 $\text{Slope} > 0$）环境下，结合 EMA12/EMA26 金叉、MACD 柱加速与 RSI 动量确认入场。
   - **Mode B 恐慌极值超跌反弹 (Oversold Panic Reversal)**：
     当标的遭遇极端非理性砸盘（$\text{RSI}_6 < 22$ 或击穿布林下轨），出现长下影线或阳线企稳（$\text{Close} > \text{Open}$ 且收盘脱离最低点 45% 以上），捕获极高盈亏比的超跌反弹机会。

3. **多级利润锁定与动态止损体系 (Multi-Stage Profit Lock & Risk Hierarchy)**：
   - **目标波段止盈 (Target Take Profit)**：设定波段预期止盈位（默认 `+8.0%`），达到后自动分批/一次性止盈平仓，锁定确定性收益。
   - **严格硬止损 (Hard Stop Loss)**：单笔亏损严格拦截在 `-3.0%`，杜绝深套。
   - **保本保盈提升 (Breakeven Lock & ATR Trailing Stop)**：单笔浮盈超过 `+2.0%` 后，ATR 追踪止损线自动推升至成本价上方，保护胜利果实。
   - **破位早退 (SMA20 Breakdown Exit)**：若持仓未能迅速发酵并下破 20 日均线，系统在小幅损耗内有序撤退。

4. **高效率动态资金预算 (Capital Budgeting)**：
   - 在高胜率信号触发时分配最高 95% 仓位预算，大幅提高资金利用效率，同时严格遵守 100 股（1手）整数倍与 T+1 锁仓规则。

## 🚀 快速启动指南

### 1. 命令行 CLI 回测 (以平安银行为例)

```bash
# 运行平安银行 (000001) v2 优化回测
python algo_trading_v1/run_backtest.py --code 000001 --start 2021-01-01 --end 2024-12-31 --tp 0.08 --sl 0.03

# 运行比亚迪 (002594) 回测
python algo_trading_v1/run_backtest.py --code 002594 --start 2021-01-01 --end 2024-12-31 --tp 0.10 --sl 0.035

# 运行贵州茅台 (600519) 回测
python algo_trading_v1/run_backtest.py --code 600519 --start 2021-01-01 --end 2024-12-31 --tp 0.08 --sl 0.03
```

**CLI 参数说明**：
- `--code`: 标的代码（如 `000001` 平安银行, `510300` 沪深300ETF）
- `--start` / `--end`: 回测时间窗口
- `--capital`: 初始本金（默认 100,000 元）
- `--tp`: 目标波段止盈比例（默认 `0.08` 即 `8%`）
- `--sl`: 严格最大硬止损比例（默认 `0.03` 即 `3%`）
- `--atrm`: ATR 追踪止损推升倍数（默认 `2.2`）
- `--pos_pct`: 仓位资金分配比例（默认 `0.95`）
